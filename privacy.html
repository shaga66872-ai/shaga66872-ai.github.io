개인정보처리방침

시행일: 2026년 10월 16일

라이브 채팅봇(이하 "봇")은 YouTube API 서비스를 사용합니다. 봇을 이용하면 YouTube 서비스 약관과 Google 개인정보처리방침에도 동의하게 됩니다.

1. 수집하는 정보

봇은 라이브 채팅에 공개적으로 표시되는 아래 정보만 사용합니다.

  • 유튜브 채널 ID와 표시 이름(닉네임)
  • 채팅 메시지 내용 (명령어 인식 용도로만 확인하며, 메시지 원문은 저장하지 않음)
  • 봇이 만든 기록: 코인 잔액, 출석 날짜와 횟수, 코인 변동 내역

2. 이용 목적

출석 체크, 코인 지급과 조회, 랭킹 표시 등 봇 기능 제공에만 사용합니다. 광고나 마케팅에 사용하지 않습니다.

3. 제3자 제공

수집한 정보를 판매하거나 제3자에게 제공하지 않습니다.

4. 보관 및 삭제

정보는 봇 운영 서버에 저장되며 봇 운영이 끝나면 삭제합니다. 본인 기록의 삭제를 원하시면 아래 이메일로 요청해 주세요. 확인 후 지체 없이 삭제합니다. Google 보안 설정 페이지에서 봇의 접근 권한을 해제할 수도 있습니다.
